## 🚀 Step-by-Step Walkthrough

### 1. 💖 Public Sponsor
1. Find any active developer with GitHub Sponsors enabled (e.g. `@egoist`, `@yyx990803`).
2. Click **Sponsor** and select the $1/month tier.
3. Badge appears within 60 seconds on your profile!

### 2. 🦈 Pull Shark (x2, x3, x4)
1. Fork or create a repository.
2. Create a feature branch (`patch-1`).
3. Commit changes and open a Pull Request against `main`.
4. Merge the PR. Repeat 16 times for Bronze, 128 times for Silver!

### 3. 🤝 Pair Extraordinaire (x2, x3, x4)
1. Create a commit containing the `Co-authored-by` Git trailer:
   ```bash
   git commit -m "Feature update\n\nCo-authored-by: Octocat <583231+octocat@users.noreply.github.com>"
   ```
2. Open and merge the Pull Request. Verify dual avatars on GitHub! Repeat 48 times for Gold!

### 4. 🌌 Galaxy Brain (x2, x3, x4)
1. Go to public repositories with **Discussions (Q&A category)** enabled.
2. Provide technical, comprehensive answers.
3. Once marked with **Mark as answer** 2/8/16/32 times, the badge and its multiplier unlock!
